WOLF INSTINCT — UNLEASHED · iPhone-Web-App

Schnellstart: index.html in Safari oder einem Browser öffnen.

Für App-Installation auf dem iPhone: Die vier Dateien index.html, manifest.webmanifest, service-worker.js und icon.png zusammen auf einem HTTPS-Webhost bereitstellen (z. B. GitHub Pages oder Netlify). Dann die URL in Safari öffnen, Teilen > Zum Home-Bildschirm. Danach ist die App inklusive 110 Karten offline verfügbar.

Die 100 Inhaltskarten und 8 Aktionskarten sind spielbar. 2 Regelkarten erscheinen im Startbildschirm als Spielhinweise und sind in der Datenbasis erhalten. Aktionskarten können deaktiviert werden.

Alle Inhalte sind lokal eingebettet. Es wird nichts an einen Server übertragen. Die Daten der laufenden Partie bleiben im lokalen Speicher des Browsers.
